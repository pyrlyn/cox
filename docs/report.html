A modular Rust terminal coding agent

cox steers the boat. The models row.

What Claude Code, Codex CLI, Copilot CLI, Pi, OpenCode, Crush, Goose, Gemini CLI and aider each got right, which parts cox adopts unchanged, and the plan for the parts none of them do well: a lossless, cache-stable, explicitly priced context.

2026-09-02 Companion files: plan.md (77 tasks, 13 phases), research.md (evidence, ledger), AGENTS.md Method: 6 Haiku research agents, 1 adversarial fact-check, author verification of Codex's manifest and crates.io

Verdict

Build it as Codex is built, run it as aider prices it. One binary, ten crates, a pure state machine in the middle (Submission in, Event out), four surfaces on the same event stream: TUI, headless stream-json, Agent Client Protocol for editors, and an MCP server exposing cox's own tools.

Adopt formats, don't invent them. AGENTS.md, Agent Skills, Claude Code's hooks and permission rules, .mcp.json, Codex's V4A patch grammar, MCP 2026-07-28, ACP 2.0. A user with a Claude Code or Codex setup gets cox without editing a file.

Route by job, price every request, never switch up. Haiku-class for titles, summaries, compaction, shell and HTTP subagents; Sonnet 5 or Opus 5 for code; Fable 5.1 only behind an explicit confirmation. Every request writes a ledger row with cache read and write tokens.

The context is the product. Tool output is archived before the model sees a truncated head/tail; identical re-reads are refused; tool schemas are deferred; the prompt prefix is byte-stable; compaction is append-only and keeps the last two turns. Nobody in the field does all six.

No test needs a model. Scripted and replay providers, golden event logs, ratatui TestBackend snapshots, PTY end-to-end. Evals stay opt-in.

The shape

Codex ships a TUI, a headless mode, an IDE app-server and an MCP server from one core because its core is a submission queue and an event queue. cox copies that boundary and makes it the test seam as well: the rollout file on disk is the same JSONL a test replays.

Ten crates, one rule

Anything that touches the network, the filesystem or a process lives behind a trait in cox-protocol. If cox-core is about to open a socket, it is in the wrong crate.

pub enum Event { TurnStarted, TextDelta, ThinkingDelta, ToolCallRequested, ApprovalRequired,
                 ToolCallOutput, ToolCallDone { result_ref }, ItemDone, Usage, Compacted { summary_ref, dropped },
                 Notice, TurnDone { stop }, Error }

#[async_trait] pub trait Provider { async fn stream(&self, req: Request, sink: Sender<ProviderEvent>) -> Result<Usage>; }
#[async_trait] pub trait Tool     { async fn call(&self, input: Value, cx: &ToolCx) -> Result<ToolOutput>; }

What nobody does well

  • Show cache hit and miss per request, and why a cache broke.
  • Truncate losslessly: a retrieval handle instead of a silent cut.
  • Refuse an identical re-read within a session.
  • Document compaction, keep it append-only, and keep the cache warm through it.
  • Stop the session when a budget is hit.
  • Ship an offline regression suite that replays the agent's own event log.

Eight mechanisms in the core

  1. Archive first. Every tool output is stored before the model sees head and tail plus expand <id>.
  2. Re-read dedup. An identical read or grep within N turns returns "unchanged, see #id".
  3. Outline reads. read takes a line range or a tree-sitter outline mode.
  4. Deferred schemas. Tools beyond the core eight are found through a tool_search tool, the way Claude Code and Anthropic's server tools do it.
  5. Byte-stable prefix. tools, then system, then instruction files, then the last cache breakpoint, then anything volatile. One changed byte in the prefix forfeits the cache.
  6. Append-only compaction on the cheap tier, keeping the last two turns verbatim.
  7. One usage row per request with cache read and write tokens.
  8. Budgets per session and per month that stop the session.

The metric that all eight move is context-token-turns: the sum over a session of tokens the model saw on each turn. Third-party savings claims for external hook stacks were not reproducible; rtok's own measurements found 3–40 %. A native agent can change what the model sees, which hooks cannot. Table §4.6 in research.md holds cox's own numbers once task T8.5 runs.

Testing without a model

  • Provider seam. Scripted fixtures and replay cassettes, re-recorded on demand with cox record and redacted. Seeds do not give bit-exact replay across providers; replaying the event log does.
  • Golden event logs. Loop scenarios snapshot the Event JSONL. The rollout file and the fixture are one format.
  • TUI. ratatui TestBackend plus insta per widget and per frame; portable-pty plus vt100 for the real binary, as Codex does.
  • Tools. tempfile trees; proptest on str_replace and V4A (parse-print round trip, edit-then-reverse identity); fuzz targets for the SSE, V4A and frontmatter parsers.
  • Evals apart from tests. A Terminal-Bench adapter and ten in-repo tasks, run on demand with a real provider, cost recorded in the ledger.

Done means

  1. A multi-turn coding session runs against Anthropic, OpenAI Responses and a local Ollama model with the same tools, sandbox on, on macOS and Linux.
  2. The workspace tests pass offline with no API key in under 90 seconds on CI, with a snapshot for every widget, transcript cell and loop scenario.
  3. A user with an existing Claude Code setup and rtok hooks gets identical behaviour without editing anything.
  4. cox stats shows cost by tier and job; measured savings exist for each mechanism; cache-read ratio from turn three onward is at least 80 %.
  5. Headless and ACP pass their conformance tests; cox mcp serves read, grep and glob to Claude Code.
  6. No unwrap or panic outside tests; cargo-deny clean; fuzz jobs green.

Method and limits

  • Six research agents on Haiku with web access: Claude Code and Copilot, Codex internals, competitors (three sub-agents), crates, specs, tokens and testing. One fact-check agent. About 550k subagent tokens, roughly one dollar.
  • The tokens-and-testing agent made only three lookups and wrote mostly from memory; its report is treated as directional and its numbers were dropped.
  • Author verifications: Codex's workspace manifest, eighteen crates on crates.io, name availability (cox, coxswain, boatswain, mizzen, brigantine are free), and the Claude API reference for models, prices, caching thresholds and thinking rules.
  • Still open: official prices for non-Anthropic providers, Claude Code's compaction thresholds, Terminal-Bench task counts, Copilot CLI internals. Each has a task that replaces the guess with a measurement.
